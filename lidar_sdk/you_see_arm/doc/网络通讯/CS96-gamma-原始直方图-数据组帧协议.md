# CS96-gamma 原始直方图数据组帧协议

## 构建与运行

- 使用 `make PRESET=gamma` 构建，板端配套统一 AM6204 内核驱动和 FPGA 直方图输出。
- 板端运行配置的 `[system]` 中设置 `work_mode=0` 并启动应用，驱动选择 `MODE_HIS_SL100` (5)。
- `LOCAL_TEST=1` 从 `./file/CS96-gamma/raw_histogram_data` 回放，文件由若干完整的 122912 字节 SLOT 连续组成，循环读取，每帧间隔约 800ms。

## FPGA 数据

每个 SLOT 为 122912 字节：32 字节头部，以及 120 个像素的直方图。每像素仅传递前 512 个 bin，每个 bin 为小端 `uint16_t`，像素数据共 1024 字节。

| 字节偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 2 | FPGA 原始 SLOT 序号 |
| 2 | 2 | 保留 |
| 4 | 2 | pixel 开始点序号 |
| 6 | 2 | pixel 结束点序号 |
| 8 | 24 | 保留 |
| 32 + p × 1024 | 1024 | 像素 p 的 bin 0～511，p 为 0～119 |

SL100 每个 SLOT 就是一个实际帧。底层沿用每 56 个 SLOT 一个帧中断的机制及缓冲区轮转配置，应用层每次取得一个 SLOT 即发送一个新帧，不等待槽号归零或帧中断。

## 上位机 UDP 包

沿用 `raw_protocal_data_packet_t` 的紧凑结构，所有多字节字段为小端。每帧 30 包，每包 4105 字节（9 字节协议头 + 4096 字节 bin 数据）。FPGA 的 32 字节头部不发送。

| 字节偏移 | 长度 | 字段 | 取值 |
| --- | --- | --- | --- |
| 0 | 1 | sof | `0xAA` |
| 1 | 2 | frame_id | 每收到一个 SLOT 自增；首帧为 1，65535 后回到 0 |
| 3 | 2 | slot_number | 固定 0，表示本帧唯一的 SLOT |
| 5 | 2 | seq_num | 0～29 |
| 7 | 2 | data_len | 4096 |
| 9 | 4096 | value | 连续 4 个像素，每像素 512 个 bin |

同一 SLOT 的 30 个包使用相同 `frame_id`。第 `seq_num` 包承载像素 `4×seq_num` 至 `4×seq_num+3`。上位机按 `frame_id` 分帧，再按 `seq_num` 排列即可恢复 120×512 的直方图；缺少任何分包即为不完整帧。连续原始模式和单次原始模式采用相同组帧规则。

每个 UDP 包超过常见以太网 MTU，会发生 IP 分片；接收侧应使用至少 4105 字节的 UDP 接收缓冲并允许 IP 分片重组。
