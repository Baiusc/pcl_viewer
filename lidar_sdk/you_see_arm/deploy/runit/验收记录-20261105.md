验证重点包括：

- 启动前签名、机型、架构、链接与路径检查；异常时不执行包内程序。
- 配置和本机标定只初始化缺失文件；模式与用户参数跨管理进程、RAM 运行目录重建后恢复。
- 同一开机内有限恢复、新一轮系统启动的稳定状态恢复，以及 FAULT/未完成恢复保持锁定。
- 真实监督下重复 start 无双实例，stop 后保持停止，mgrd 崩溃后重拉，三次连续启动失败熔断。
- FAULT 保持管理 API 就绪，不被监督器误判并重置业务状态。
- 镜像合入保留串口和关机项、备份旧 S99user、不追随越出 TARGET_DIR 的父目录链接，输入不完整时不移除旧入口。
- 回波/坐标设置写入失败不改变内存参数，重复设置不重写持久文件。
