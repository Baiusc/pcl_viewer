# pcl_viewer

# 激光雷达点云可视化PC软件Lite版 

目标平台：
ubuntu 20.04及以上
Win10 及以上

开发语言：
不限 跨平台友好

功能：
1、离线点云可视化。读取、解析、可视化雷达设备离线保存的单帧或多帧点云 csv txt 格式的一个或多个文件。
2、在线点云可视化。根据不同型号的雷达的SDK进行开发。
3、点云的可视化、按？着色、选点信息。

开发要求：
尽量复用pcl_viewer仓库的现有代码。

支持的雷达设备型号：
支持 alpha转镜雷达、beta薄款转镜雷达、面阵全固态雷达（FL6031、FL6532芯片）
